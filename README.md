# Network Port Scanner

## Description
This project is a Python-based network port scanner developed
to identify open TCP ports and running services on a target system.

## Features
- Multi-threaded scanning
- Service detection
- Report generation
- Ethical testing

## Tools Used
- Python 3
- Linux (Parrot OS)
- Socket Programming
- TryHackMe Authorized Labs

## Ethical Notice
All testing was performed on authorized systems only.
